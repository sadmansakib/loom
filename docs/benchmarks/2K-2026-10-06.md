# 2K — Tool-spec compaction (2026-10-06)

Step 2K of `docs/plan-iteration-2.md`: compact the serialized schemars
JSON (V19) — shorter descriptions, tighter schemas — without breaking
schema↔parser agreement or model accuracy. Commit `2c6dfee`
(`feat(tools): compact serialized tool specs`).

## Protocol

- `LOOM_EVAL_TASKS=B1,B2 LOOM_EVAL_RUNS=5 cargo test -p loom-cli --test eval
  -- --ignored --nocapture eval_live`; model deepseek-flash, provider
  deepseek, price window peak. Reports: `target/eval/report-B{1,2}-deepseek-flash.json`.
- Gates before the run: `cargo test --workspace` **410 passed / 0 failed /
  10 ignored**; `cargo clippy --workspace --all-targets` 0 warnings;
  `cargo fmt --check` clean.
- Baseline: the 2G record (same tasks, same model, N=5).

## What changed

`schema::parameters` now renders the same struct schema the tool parses
with, minus the bytes the model does not need:

- drop `$schema` / `title`;
- inline `definitions` and collapse the single-element `allOf` a `$ref`
  arrived in (so `verify`'s `Scope` enum is a plain inline schema);
- `compact` removes `default` and the Rust-integer `format: "uint"`,
  rewrites an integral `minimum` from `1.0` to `1`, and collapses a
  `oneOf` of single-value string enums into one `enum` list.

Every tool's top-level description and field docs were shortened.
Schema↔parser agreement is unchanged: the per-struct
`crate::schema::agreement::check` still passes, and both the closed-object
and the new noise-free assertions run over the shipped specs.

## Reading

- **DoD met for B2**: turn count does not regress (3.4 → 3.0; median 3,
  min = max = 3), input −22 % and cost −24 %, all 5 runs 3 turns with
  0 failed calls. The serialized-spec cut is deterministic (−322 est
  tokens, −21.3 %) and is the plausible mechanism for the B2 drop.
- **B1 is not a 2K target.** Its specs are 529 est tokens against a
  ~24 K transcript; the run-to-run spread (V17: 7–11 turns here, 6–10 at
  2G) fully covers its turns/input/cost delta, and nothing in 2K touches
  its dominant `tool_results` term. No B1 change is claimed.
- **Variance note.** An earlier N=5 B2 sample of the same code showed
  mean 4.6 turns, driven by a single 9-turn run (≈4,000-token reasoning
  replay, a stray wrong-path write) — exactly the single-run noise V17
  warns about. The N=5 table above is the recorded measurement; the two
  samples agree that the median is 3.
- No invariant regression: schema↔parser agreement, replay equivalence,
  and the closed-object spec invariants all still hold.
